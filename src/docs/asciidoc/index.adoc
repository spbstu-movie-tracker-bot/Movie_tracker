== Admin: User List

Admin-only endpoint, requires `ADMIN` role. Returns all registered users.

=== Request

`GET /admin/users`

Header: `Authorization: Bearer <telegramId>:<hash>`

=== Response

operation::admin-users[snippets='http-request,http-response,response-fields']

Each user has a role: `USER` (default) or `ADMIN`.
